# VEYRA offline maps

Publisher: **Technology Timeline**.

This repository distributes country map packages for VEYRA. It does not contain the private application source code or user data.

## Country choice

Users choose which available country to download inside VEYRA. No country is mandatory or downloaded automatically. Only verified, released packages appear in the catalog; the existence of this repository does not mean worldwide coverage is already available.

## Releases

A package contains a PMTiles basemap, an offline routing graph, a street/address/place search index, and, where provided, a road-identity index. The catalog records exact byte lengths, SHA-256 checksums, data dates and provenance. Downloads are hosted by GitHub Releases, separately from the original data publishers.

Packages are beta data products. Offline navigation cannot know current road closures, current traffic or changes made after the source date. Follow road signs and applicable regulations. OpenStreetMap coverage and completeness vary; no package guarantees complete civic addresses, vehicle restrictions or points of interest.

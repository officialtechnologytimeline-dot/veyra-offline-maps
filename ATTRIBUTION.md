# Map data attribution and provenance

## OpenStreetMap

© OpenStreetMap contributors. OpenStreetMap data is available under the Open Database License (ODbL) 1.0:

- https://www.openstreetmap.org/copyright
- https://opendatacommons.org/licenses/odbl/1-0/

VEYRA routing, search and road-identity databases derived from OpenStreetMap are distributed under ODbL 1.0. This does not license the private VEYRA application code. The corresponding source extract and converted build input are identified in each release; the converted build input is supplied with the release.

## Geofabrik

Regional OpenStreetMap extracts are obtained from https://download.geofabrik.de/. Original dataset URLs and dates are recorded per country. Geofabrik is the source of the extract, not the publisher or operator of VEYRA.

## Protomaps

Basemap archives are extracted from dated Protomaps daily builds:

- https://docs.protomaps.com/basemaps/downloads
- https://maps.protomaps.com/builds/

The basemap incorporates OpenStreetMap and Natural Earth. Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/.

These PMTiles basemap extracts are distributed as ODbL Produced Works with the required OpenStreetMap attribution. Source dates and schema versions are recorded in release metadata.
